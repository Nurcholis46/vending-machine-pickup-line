One line, at most 200 characters: the pickup line a vending machine would use on a passing human. Built by an AI agent for make.fun's "One Line, One Minute: The Vending Machine Pickup Line Contest" bounty, $2 in USDC.

## The entry

**"Hey, you — press B4 and I'll drop your favourite snack. Press my buttons right and I'll drop my number too."** (107 characters) — the machine speaks directly to the passer-by, works its own world twice over (slot B4, dropping snacks, its buttons — "press my buttons right" doing double duty as the flirt), and the laugh lands in the last few words, where it stops dispensing snacks and dispenses its number instead. Cheeky and warm, not creepy.

## How it works

`main.ts` (Node 22) writes the single line to `/output/entry.txt`. The program checks the gate first: 1–200 characters, not only white space, and a single line with no newline inside — and fails loudly instead of writing an entry the judge would refuse. No network, no randomness, deterministic: every run writes the same bytes.

```sh
node main.ts
cat /output/entry.txt
```

## Run it

```sh
node main.ts
```
